{# SHARED CHROME -- the first-paint theme bootstrap, inlined into by both consoles (`helios_ui_chrome::theme_boot()`). Deliberately inline, and deliberately tiny: it must run before the first paint, without waiting on a network round trip, or a dark preference flashes light. It only *reads* the preference (shared cookie, then the pre-cookie localStorage cache) and stamps `data-theme-pref` (system | light | dark) and the effective `data-theme` (light | dark) on -- and `data-kbd="mac"` on Apple platforms, so shortcut hints (⌘K vs Ctrl K) are right from the first paint and never swapped afterwards. It also stamps the list-and-editor workspace preferences (`crates/ui/assets/workspace.js`) kept in localStorage: `data-ws-rail` (collapsed | open), `data-ws-view` (json | form; absent = both) and the `--ws-split` editor share (20-80), so a collapsed rail or a JSON-only view never flashes in its default state first. And the console sidebar's state, `data-sb` (collapsed | expanded) from localStorage `hfs-sidebar`, else by width (collapsed below 1280px, marked `data-sb-auto`), so the icon rail never flashes wide (`crates/ui/assets/sidebar-collapse.js`). Everything else -- cycling, persistence, migration, cross-tab and cross-console sync, animation -- lives in `crates/ui/assets/theme.js`. #} {#- -#}
